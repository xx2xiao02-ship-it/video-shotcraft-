3.2 组件层媒体引用（112 处 / 31 文件）

① 组件自带装饰素材（staticFile 固定资源，不可替换）：

  • 相机类共用 textures/live/*.png：projects-full / projects-empty / card4-hires / card1 / card7 / paper1 / paper3 / nav / float-search / float-stats / wbr-full 等
  • 单文件示例：StreamResponse ./agent-stream.jpg

② 外部素材输入 props：几乎为零——全库仅 PageCam2D 的 src: string（仍是 staticFile 路径参数）。用户素材无法进入组件画面，只能通过 shot.material 做全屏底。

3.3 注入缺口

  • ShotData.baseVideo 已在类型定义，但契约注册表无映射、ShotView 未使用——组件级媒体输入通道半成品
  • 素材 opacity / 位置 / 遮罩不可调（编导侧无法控制素材呈现强度）

四、三类数据流总览

🎨 色彩→风格中心 C4→theme-pack.json→current-theme.json→storyboard.style→DynamicVideo 变量+props→221 组件
🔤 文字→无公共入口→字幕 4 预设（硬编码）+组件字体族（15+ 硬编码）→字体族不统一
🖼️ 图片视频→素材库 C5→shot.material→渲染层素材视频（opacity 0.6 硬编码）+组件 staticFile 装饰（不可替换）

五、治理建议（优先级排序）

P1 · 文字公共参数入 C4（推荐先做）

  • C4 新增文字参数 4 项：fontFamily（公共字体族，中文场景统一思源黑体/得意黑）、captionSize（字幕字号 32/36/40）、captionWeight（400/600/800）、captionColor（白/#ffe600 等）
  • 注入链：theme-pack.json → current-theme.json → storyboard.style 扩展（fontFamily/caption*）→ DynamicVideo 字幕层 + TranslatedShot 注入 fontFamily prop
  • 组件字体族：经 CSS 变量 --font-family 覆盖（不动 221 组件源码，最少侵入）

P2 · 媒体参数半参数化

  • 素材视频层 opacity / objectFit 入 storyboard（shot.materialOpacity 0.3~1.0），编导台可调素材呈现强度
  • fallback 大字字号/透明度参数化（当前 96px/14% 硬编码）

P3 · 组件媒体输入契约（大工程，可选）

  • 启用 ShotData.baseVideo：契约注册表加 media: 'imageSrc' 类映射，让部分组件接受外部素材（如卡片类替换 card4-hires.png）
  • 组件 staticFile 装饰素材目录化（textures/live → 可替换资源），用户素材可进组件画面
