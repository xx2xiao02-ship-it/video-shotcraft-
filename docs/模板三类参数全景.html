P1 · 文字公共参数入 C4 ✅ 已落地（commit 92907e8）

  • fallback 大字字号/透明度参数化（fallbackSize 默认 96 / fallbackAlpha 默认 0.14）

P3 · 组件媒体输入契约 ✅ 已落地并渲染验证（commit 92907e8）

  • 契约 ui-entrance/clipcard-looping：propsMap media → src / durationInFrames → durationInFrames；ClipCard 增加 http(s) 分支（src.startsWith('http') 走服务端流，本地才 staticFile）
  • ClipCardLooping 单卡模式：src 存在时渲染素材卡（size/loopDuration/captionSize 按时长自适应），无 src 保持原三场景演示
  • build-storyboard：素材主体镜头 35% 概率写 media=http://127.0.0.1:8765/api/library/video?path=...（零复制）；pit 走 remotion/video-local/element
  • 契约类型修复：string 类组件（lead-word-zoom-assemble/scramble/scramble-decode/split-text-stagger/font-weight-pump/terminal-typewriter/typewriter-error-retype/单字类）补 textAs: 'raw'；数据牌组件（odometer/counter-confetti）enabled:false 不注入整句
  • 渲染验证：2376 帧全通过，成片 19.5MB；media 镜头 2 帧抽查素材卡正常显示

✅ 数据调用便利性规则：四端字段名完全一致（THEMES ↔ current-theme.json ↔ style ↔ 组件 props），build-storyboard 一次读取全量注入，素材经服务端流零复制。
