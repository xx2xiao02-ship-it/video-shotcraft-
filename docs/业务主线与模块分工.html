Video ShotCraft · 业务主线与模块分工
定位：一条口播文案 → 一支成片 · 本地自动化视频生产线（文案进、成片出，Remotion 渲染，操作台 127.0.0.1:8765）
一、业务主线（主流程闭环）
① 文案输入
编导表单贴全文，不拆句
模块：操作台 console-ui
产物：_input.txt
→
② 定调
视频类型 · 时长 · 主题预设 · A/B/C 模式
模块：操作台 console-ui
产物：表单参数
→
③ TTS 配音
edge-tts 男声合成 + 按句分配时间轴
模块：director/tts.py
产物：voiceover.mp3 + timing.json
→
④ 自动分镜 ★核心
叙事分级 L1 六类 → L2 26 类 → 镜头卡；坑位治理（slot+素材角色+A/B/C pit）；时长约束 1.5–5s
模块：director/build-storyboard.mjs + taxonomy.json
产物：storyboard.json
→
⑤ 素材匹配
语义词典提取标签 → 3396 镜头索引检索 → 打分排序；未命中 fallback 渐变+关键词
模块：materials/_index.json
产物：素材路径/占位
→
⑥ Remotion 渲染
DynamicVideo 驱动，主题注入 CSS 变量，字幕样式统一
模块：director/render.mjs + template/
产物：promo.mp4
→
⑦ 交付改片
成片预览 → 动效工作台多轨改 → 剪映导出
模块：workbench / jianying-export
产物：成片 + 可编辑工程
★ = 业务核心价值：叙事分级 + 坑位治理 + 素材匹配都在这一步，A 模式已闭环（最近一次 19 镜头）。
二、三条模式主线
A 模式 · Remotion 主导 ✅ 已跑通
模板+文字是主体，素材做人像/背景点缀。适配知识口播、干货讲解、数据型内容。当前主战场。
B 模式 · 人像口播主导 🟡 未完成
真人口播画面是主体，Remotion/素材穿插做标注与转场。需要人像源与 B 模式坑位配置。
C 模式 · AIGC 素材主导 🟡 未完成
AIGC 生成素材是主体，Remotion/人像做文字标注。适配故事感、氛围感、影视化内容。依赖 AIGC 生成接口回填。
三、模块分工（五层架构）
层1 · 人机入口（操作台）
console-server.mjs / console-ui.html
编导表单、进度/日志、素材库上传与浏览、主题预设、视频预览、任务 API。用户唯一触点。
状态：运行中 ✅
层2 · 生产管线（大脑）
director/ · 制作管线
tts.py（配音+时间轴）→ build-storyboard.mjs（叙事分级/坑位/素材/时长）→ render.mjs（渲染）；含 taxonomy.json、theme-pack.json、校准页、索引脚本。
状态：A 模式闭环 ✅
层3 · 渲染引擎
template/ · Remotion 模板
DynamicVideo.tsx 主驱动，TemplateAdapter props 转译，aifl 组件库（字幕/数字滚动/闪切/2.5D 相机），4 种字幕样式，主题注入。
状态：A 模式可用 ✅
demos/ · 镜头卡库
10 类 221 个镜头卡 TSX 参考实现（camera/data/effects/interaction/opening/outro/rhythm/transition/typography/ui-entrance），供分镜选卡与工作台拖入。
状态：资产就绪 ✅
层4 · 资产底座
materials/ · 素材库
3396 镜头索引（商务 1280 / 城市通讯 996 / 高楼 442 / 家庭 363 / AI 科技 288 / 4K 商务 27），缩略图、上传、预览。
状态：已上线，标签体系待治理 🟡
assets/ · 组件与音频
可复用 Remotion 组件、页面素材采集脚本、5 首 BGM + 16 类 149 个 SFX。
状态：就绪 ✅
层5 · 交付出口
workbench/ · 动效工作台
剪映式多轨编辑：镜头/字幕/音效轨，属性面板逐项改，demo 动效拖上轨，Remotion 一键导出（像素级校验）。
状态：开发中 🟡
jianying-export/ · 剪映导出
成片拆成剪映工程草稿：镜头切段/字幕原生轨/独立音轨可编辑。
状态：Mac 验收，Windows 未验证 🟡
gallery/ · 样片画廊
在线展示 214 条动态样片，搜索/筛选/预览，对外展示与选卡入口。
状态：就绪 ✅
