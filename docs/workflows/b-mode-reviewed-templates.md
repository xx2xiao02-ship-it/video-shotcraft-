## 固定工作路径

大模型是编导：负责语义、镜头分组、叙事安排和已有模板的内容参数；模型不生成场景源码，不设计新组件。`visual` 只作编导说明，不能作为绘图或执行指令。模型给出的 `shotCard` 只是一项提议，必须通过后端的真实候选确认；提案检查通过不能标成选卡通过。模板最终实现由后端复制原源码并绑定参数完成。

原版允许有限蒙皮、纯文镜G5图解及有理由的语义偏离。用户最新确认保留“仅已审模板、禁止补画”，撤销本地后加的“候选外不放行”，恢复原版有理由的语义偏离。不应将本地约束冒称为原版原文。

1. 从历史真实媒体审查记录建立源码版本登记。登记必须包含模板标识、源码及依赖哈希、横竖版样本哈希、参数绑定和布局检查结果。
2. 使用上游 `card_match.py`，输入索引只保留登记且源码版本未变化的模板。按语义、素材、原生时长排序；不把全目录或开场短卡池直接当语义候选。
   开场窗口为前 8 秒，窗口内起始的镜头须同时满足：原卡完整时长不超过 3 秒；实际镜头时长（含驻留）目标约 2.4 秒、上限 3.4 秒。后者按真实起止时间核验，不能用短卡名称、较短的声明时长或驻留绕过。需要拆分时依据原配音字级时间戳和自然短句编排，不重新生成配音、不截断模板动作；当前句粒度无法表示时先保留明确修订项，不自动换卡或改写已批准分镜。
3. 编导比较完整已审目录（当前108张），逐镜明确选卡和业务参数。保留上游语义/素材可行性与排序，调用时以 `--top <已审索引总数>` 返回该语义下全部可行推荐，不再限前三；这项推荐数量扩展是本地适配，原版默认仍是3。推荐外按原版 `- 语义偏离：语义词 ← 至少四字的具体理由` 写在本镜SHOTBOOK，由原解析器检查。理由不豁免素材、源码、原生时长、参数或字级规则。不得事后伪造候选或自动选择每种语义的第一名，缺选卡记录只补录编导正式选择。
   连续30镜不同观点不重复；同一观点的强关联承接可例外：前后镜 `templateParams.templateContinuity.pointId` 相同，后镜逐次写 `continuesShotId` 和至少四字 `reason`，完整承接链供人审；单独同组、短理由、未来或循环引用不能放行。候选比较报告 `qa/card-candidate-comparison.json` 记录完整可用库、每镜各语义推荐、当前选卡、候选外理由、近期已用和未用推荐，不将报告等同于最终画面验收。
4. 候选、语义、SHOTBOOK 和审查登记绑定版本。输入改变后必须重新生成候选。预检、实现、样片、整片和交付再次核验。
5. 只用模板原生已审参数修改文字、配色及素材。禁止新增图解、隐藏绘图层或在外层CSS覆盖几何结构。原卡无法容纳内容时重新选卡或修改分镜。
6. 复用原配音和现有人物口型素材，保留原片与旧候选。模板替换仍须检查字级、素材时间范围、布局、对比度、实际编码视频和音轨一致性。

## 镜头起始内容与关键词等待

逐字时间对齐必须与内容承接共同规划。纯文字/图形镜头首秒内应有对应当前解说的有效文字；仅有色块、编号、箭头或底部字幕不能代替主体内容。关键结论保持原发声锚点，不能因空白而提前显示。

`talkcraft-content-onset.mjs` 在字级计划编译时检查每镜最早有效内容时间；无人物承接、无已落地媒体且首段文字过晚时返回 `CONTENT_ONSET_GAP`。人物声明仅代表规划职责，实际人物素材仍由原素材体检核验；媒体路径存在也不能替代原版素材准入和人审。检索描述、缺失媒体、延期文字或标点不能用于放行。

失败回到编导：根据当前语义调整原卡公开文字参数或短语锚点，必要时按自然短句重新编排、从已审候选重选卡。禁止自动补画、装饰填空、强改 context 提前泄露未来结论。修订预览独立保存，经过用户审核后才应用正式分镜；原配音、人物和原片保留。

## 验收与历史边界

`technical-reviewed` 仅表示历史模板级真实渲染、参数绑定和布局检查已完成；不代表历史用户审美验收或本片通过。登记不修改历史 `production=false` / `userAccepted=false`。当前成片仍须独立审片及用户验收。

没有证据、源码改变、候选过期、候选外缺原版理由、模板外补画或30镜重复缺同观点承接依据时阻断，并显示具体镜头及修复方法。没有关闭门禁的开关，也不通过重配音、重生数字人掩盖编导问题。

- 仅原卡动效允许0.85～1.15倍速。以原生首尾帧跨度 / 输出首尾帧跨度计算实际速度，整数帧量化后仍不得越限；不是把时长简单增减15%。首尾完整、动作顺序不变，不能裁切、倒放或改原卡运动参数。
