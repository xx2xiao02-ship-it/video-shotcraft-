# B 模式数字人主体保护

数字人生成仍只覆盖已批准的 `person` 区间。修复抠图只处理本地已有素材，保留原视频、原音轨、时间轴及原成片，不自动提交 RunningHub。

## 生成与渲染

- `talkcraft-digital-human.mjs` 的绿优势度遮罩移除绿幕。主体完全不透明区域保留 RGB，只在抠像边缘抑制绿色溢色；对 alpha 进行两级闭运算修补小孔。此处理不能保证任意绿色服装都可安全抠取，实际主体边缘仍需人审。
- 输出使用 VP9 alpha WebM，核验 alpha 标记及实际解码帧数，不使用缺失的容器 `nb_frames` 冒充帧数。
- 生成数字人通过 `OffthreadVideo transparent` 合成；真人输入保留原视频逻辑。不得把透明视频当作不透明视频解码。
- 历史素材有问题时另建修复资产目录，只重渲受影响人物镜头，按原帧区间替换底片，原音轨直接复制；拒绝覆盖原片。

## 验证与审核

- 自动回归用合成绿幕素材检验深色主体、原色保留、小孔修复及帧数；它只证明算法对应规则，不证明本片视觉合格。
- 修复成片核验完整解码、分辨率、帧数、音轨及原片哈希。修复片入口同时校验视频哈希和当前源码绑定，拒绝展示过期结果。
- 主体边缘、头发、手部、衣服及肤色观感由用户看片确认。机器绑定始终保留 `visualVerified=false`、`userAcceptance=false`，不沿用旧片人审通过记录。
