# 07选卡理由补全与完整复检

技术可行的choiceId不证明语义推荐已通过。每个修订窗口在发送前显式携带selectionReasonContract：正式字段路径、当前镜允许的语义键、最少四个非空白字符，以及各方案在原索引中的语义。原版card_match和已审选卡门禁仍作最终判断，不能把技术候选追加为语义推荐。

07对候选外且缺少本镜理由的选卡产生SELECTION_DEVIATION_REQUIRED结构化问题。候选门禁失败时，同时运行确定性原生展示诊断，将全部问题与本次完整提案绑定落盘。局部修复成功而后续复检失败时，下一次补全从该事务的已恢复提案继续，保留成功镜，不能回退旧正式草稿、漏掉新增问题或反复锁定未通过的镜头。

优先免费恢复当前绑定的原始返回；仅在该原始返回内存在同镜、同卡、同语义的真实理由时才可处理可确定的结构错误。空理由不是结构错误，不能从intent、visual、holdReason或其他模板旧理由自动编造。模型创作补全须依用户本次付费授权，不自动追加调用。

正式节点通过需候选、素材、原生展示、字级、时间及其余原有检查全部通过；局部编译成功不等于07通过。原始返回、真实配音、数字人及时间轴保留。所有发布继续使用当前节点事务和原子发布，不在失败时覆盖正式任务。
