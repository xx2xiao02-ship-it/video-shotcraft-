# 07选卡理由补全与完整复检

技术可行的choiceId不证明语义推荐已通过。每个修订窗口在发送前显式携带selectionReasonContract：正式字段路径、当前镜允许的语义键、最少四个非空白字符，以及各方案在原索引中的语义。原版card_match和已审选卡门禁仍作最终判断，不能把技术候选追加为语义推荐。

07对候选外且缺少本镜理由的选卡产生SELECTION_DEVIATION_REQUIRED结构化问题。候选门禁失败时，同时运行确定性原生展示诊断，将全部问题与本次完整提案绑定落盘。局部修复成功而后续复检失败时，下一次补全从该事务的已恢复提案继续，保留成功镜，不能回退旧正式草稿、漏掉新增问题或反复锁定未通过的镜头。

优先免费恢复当前绑定的原始返回；仅在该原始返回内存在同镜、同卡、同语义的真实理由时才可处理可确定的结构错误。空理由不是结构错误，不能从intent、visual、holdReason或其他模板旧理由自动编造。模型创作补全须依用户本次付费授权，不自动追加调用。

正式节点通过需候选、素材、原生展示、字级、时间及其余原有检查全部通过；局部编译成功不等于07通过。原始返回、真实配音、数字人及时间轴保留。所有发布继续使用当前节点事务和原子发布，不在失败时覆盖正式任务。
# 重复免费恢复

07局部编译已成功但候选复检失败时，工作目录中已有分镜是正常状态。免费恢复须重新核验本次不可变请求、原始响应回执和任务绑定后再编译、复检；不能被新生成的防重复计费门禁拦住。缺失或被改动的证据仍拒绝恢复，新生成对已有分镜的保护保持不变。

重编译的派生分镜和SHOTBOOK如与已保存版本不同，先在qa/editorial-free-replay-artifacts按内容哈希保留旧产物再更新；相同内容重复保存直接复用。原始模型响应始终保留。页面07阻断清单优先显示经过原始响应和当前输入指纹验证的补全事务问题，不把正式草稿的旧问题混入当前恢复结果；此状态展示不发布提案、不标记节点通过。

qa/editorial-input-preflight下的发送前自检报告属于只读诊断，新增报告不得改变节点事务的制作输入指纹，也不随节点发布覆盖。真正的editorial-selection-request、ark-editorial-response、配音、字级时间轴和素材绑定仍保持原有指纹与回执检查。

素材查询列表仅在每项明确给出唯一field与materialQuery时转换为字段映射，原始列表及中文发现词等元数据保留在修复回执；缺项、重复或未知字段不猜测。换模板时，仅根据本次已核验响应中明确的绑定字段和相符research.displayField恢复同一展示镜的真实来源文件；不得推断新槽、移动展示镜、覆盖非空槽，来源身份、文件哈希、授权、语言和人物标签仍按原检查执行。


明确来源引用优先于待采集检索提示：恢复时必须保留并验证本次原始返回的 bindingRef（请求ID、本镜、原始绑定全文共同计算），且目标槽、资料身份、文件哈希、授权和人物标签仍须全部核验。检索提示原文不改，回执同时记录 discoveryQuery、sourceQuery 和 bindingRef；没有有效引用时继续严格拒绝查询冲突。

候选检查可能先于07规划复检终止：恢复入口必须按当前文件指纹与本次节点错误全文同时匹配候选/规划报告，不先读旧规划记录，也不按时间戳猜最新。图形比较失败的发送合同须列出原目录数据信息图分类的真实卡及具体理由要求；由编导创作比较理由，程序不代写。
