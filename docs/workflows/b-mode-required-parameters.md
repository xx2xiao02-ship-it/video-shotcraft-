- 实际发送投影在响应合同旁提供 `parameterContracts`，逐镜逐合法选卡列出必填业务字段、类型和允许空串的原卡政策。删除带空 `cardProps` 的响应示例，禁止模型以空对象代替内容。
- 发送前独立从正式目录重建并比对参数合同；遗漏、篡改即阻断发送。局部编译在应用任何修订前聚合全部必填字段错误，保留后续原版类型、步进、时长、素材和构图校验。
- 本检查不填内容、不复制演示默认值、不把素材来源事实交给模型补造。原版明确允许的空字符串仍需显式给出；空格不等于获准空串。
- 已编译但后续被严格校验拒绝的返回也可免费复检。须核对当前任务、请求、输入哈希、提交回执、完整原始返回和编译缓存哈希；旧版本缺解析文件指针时仅由当前回执的已核验原文恢复，不扫描或串用旧记录。
- 重复继续不追加模型调用。原始返回确实漏掉创意内容时如实阻断；不得手工补造或标记通过。继续至14的前提是正式校验实际通过。
