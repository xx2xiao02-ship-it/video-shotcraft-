# 音频素材库接入

- 素材按背景音乐 `bgm` 与音效 `sfx` 分类，不按 A/B 模式分类。原始文件不迁移、不覆盖；旧 `/api/library/music/*` 保留兼容。
- `materials/_audio-index.json` 独立记录 `kind + source + name`、大小、修改时间、SHA-256、时长（秒）、人工标签和授权状态。读取列表不写索引，文件变化后索引失效。上传时建索引；现有文件可显式建档或在保存标签时建档。
- 制作台仅推荐文案命中标签、索引有效且授权标记为“自有/已授权”的 BGM。推荐不会自动选曲或创建任务；音效本阶段只做分类、试听和建档。
- A 模式提交渲染时传本次选曲快照；B 模式在样板镜阶段将选曲锁入工程。旧客户端仍沿用全局偏好，已生成工程和成片不追溯修改。新合成视频的 BGM 片尾默认 0.5 秒淡出。
- 素材匹配预览需 `SHOTCRAFT_MATCH_PREVIEW=1` 显式开启，仅返回逐镜 `pending` 建议，不写入任务、素材索引或成片；代码默认关闭。当前主线 8765 启动环境已显式开启。
