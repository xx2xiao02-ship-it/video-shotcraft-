# 视频脚本总纲生成设计文档 v1.0

## 1. 核心思想

视频脚本不是"文案→TTS→逐句切镜头"，而是**双层约束生成**：
- **时长约束**：镜头组 TTS 时长 × Remotion 模板时长，互相匹配
- **叙事约束**：镜头类型 × A/B/C 模式，决定素材和模板怎么分工

---

## 2. 完整流程

```
文案输入（500字口播稿）
  ↓
第一步：镜头组划分（叙事段落）
  ├─ 按叙事结构拆成 N 个镜头组
  ├─ 每个镜头组 = 一个完整的叙事段落（钩子/痛点/论点/论据/金句/行动）
  └─ 镜头组之间是大的叙事转折
  ↓
第二步：镜头组内拆坑位（时间对齐算法）
  ├─ 每个镜头组内部 → 按语义权重拆成 k 个镜头坑位
  ├─ 每个坑位 = 一个 shot（一个镜头切换点）
  └─ 坑位时长加起来 = 镜头组 TTS 总时长
  ↓
第三步：按镜头组做 TTS
  ├─ 整段语音一起合成
  ├─ 组内句子间加自然停顿（0.3-0.5s）
  └─ 组间加镜头切换停顿（0.5-0.8s）
  ↓
第四步：第一层约束 → 时长×模板匹配
  ├─ 每个坑位的时长 → 从模板市场选时长匹配的模板
  ├─ stretch 模板：可变速适配任何时长
  ├─ fixed 模板：只在最佳时长 ±15% 内选
  └─ loop 模板：金句/长镜头专用
  ↓
第五步：第二层约束 → 叙事×坑位配置
  ├─ 每个坑位的语义 → 镜头类型
  ├─ 按 A/B/C 模式查 pitByL2
  └─ 输出完整坑位配置（subject/content/position）
  ↓
storyboard.json（最终脚本总纲）
```

---

## 3. 镜头组 vs 镜头坑位

| 概念 | 定义 | 粒度 |
|------|------|------|
| **镜头组** | 叙事段落（钩子段/痛点段/论据段/金句段/行动段） | 粗，一个视频 5-8 个镜头组 |
| **镜头坑位** | 单个镜头（一次镜头切换） | 细，一个镜头组 2-4 个坑位 |
| **总镜头数** | 所有镜头组的坑位总和 | 30-50 个 |

### 举例

**镜头组：论据段（举例+数据）**
```
镜头组 A（论据段，总时长 5s）
  ├─ 坑位 1（数据，2.5s）："90% 的人收藏完就再也没打开过"
  │   → 模板：data/axis-rescale
  │   → 坑位：local-material 背景 + text element
  │
  └─ 坑位 2（举例，2.5s）："就像你买了一柜子书，每本都翻了两页"
      → 模板：ui-entrance/card-stack
      → 坑位：remotion + video-local element
```

## 4. 镜头组内拆坑位的时间对齐算法

### 输入
- 镜头组总时长 `T`（TTS 出来的语音长度）
- 镜头组的语义结构（比如：论点 + 数据 + 举例）

### 输出
- N 个镜头坑位，每个坑位有：时长 `t_i` + 模板 `shotCard_i` + 坑位配置 `pit_i`
- 约束：`Σ t_i ≈ T`（误差 <0.5s）

### 算法步骤

```
镜头组总时长 T = 5s
    ↓
第一步：按语义权重预拆
  论点（重要）  → 建议 1.5s
  数据（核心）  → 建议 2s
  举例（辅助）  → 建议 1.5s
    ↓
第二步：每个语义单元 → 从模板市场选时长最接近的模板
  论点 1.5s → 选 blur-slide（推荐 3.8s，stretch 可变速到 1.5s）
  数据 2s   → 选 axis-rescale（推荐 4s，fixed，±15% 内只有 1.7-2.3s 可用）
  举例 1.5s → 选 card-stack（推荐 3s，stretch 可变速到 1.5s）
    ↓
第三步：校验总时长
  1.5 + 2 + 1.5 = 5s ✓
    ↓
第四步：时长微调
  stretch 模板：直接变速（动画完整）
  fixed 模板：只在 ±15% 内微调，超了就换模板
```

### 关键规则

| 情况 | 处理 |
|------|------|
| 语义单元太短（<1.5s） | 和相邻单元合并成一个坑位 |
| 语义单元太长（>5s） | 拆成两个坑位（一个讲、一个演示） |
| fixed 模板时长不匹配 | 换 stretch 模板，或调整语义单元拆分 |
| stretch 模板 | 直接变速，不用管时长 |
| 金句/重点 | 强制给 loop 模板，时长随便拉长 |

## 5. 四层坑位模型

### L0：全局模式（一次选择）
| 模式 | 主导 | 补充 | 适合内容 |
|------|------|------|---------|
| **A** | Remotion 模板主导 | 素材/人像做背景或点缀 | 知识口播、干货讲解、数据型 |
| **B** | 人像口播主导 | Remotion/素材穿插做标注和转场 | 真人口播、访谈、教程 |
| **C** | AIGC 素材主导 | Remotion/人像做文字标注 | 故事感、氛围感、影视化 |

### L1：镜头主体（谁主导画面）
| 选项 | 说明 |
|------|------|
| `remotion` | 模板本身是视觉主体 |
| `local-material` | 本地素材视频是主体 |
| `aigc-material` | AIGC 生成视频是主体 |
| `person` | 人像口播画面是主体（B 模式专用） |

### L2：内嵌元素（主体里填什么）
| 选项 | 内容 |
|------|------|
| `text` | 口播文案文字 |
| `image` | 静态图片 |
| `video-local` | 本地素材片段 |
| `video-aigc` | AIGC 新生成视频 |

### L3：内嵌位置（内容放哪里）
| 选项 | 位置 |
|------|------|
| `background` | 全屏背景（可暗化/模糊/降饱和） |
| `element` | 模板局部框（视频位/图片位，有边框/标注/标题） |

---

## 6. 模板时长体质市场

| 体质 | 数量 | 含义 | 用法 |
|------|------|------|------|
| **stretch** | 144 (66%) | 归一化时间轴（useT，t∈[0,1]），任何时长动画都完整播完 | 变速适配，首选 |
| **fixed** | 70 | 绝对帧号编排，改时长会残缺或静止等待 | 只在最佳时长 ±15% 内用 |
| **loop** | 3 | 无限循环 | 金句停留/氛围背景 |
| **static** | 1 | 无动画 | 封面/静态背景 |

### 时长分配策略
- **短分镜（<2s）**：快节奏模板（glitch/scramble/smash）
- **中分镜（2-4s）**：标准模板（blur-slide/cel-flash）
- **长分镜（4-5s）**：循环模板（orbit/marquee/ticker）

## 8. 关键决策点

1. **镜头组划分**：按叙事结构（钩子/痛点/论点/论据/金句/行动）
2. **坑位拆分**：按语义权重 + 模板时长匹配
3. **TTS 顺序**：先分镜头组，再按组合成语音
4. **两层约束**：时长约束选模板，叙事约束定坑位
5. **A/B/C 模式**：决定整体基调，每个镜头按模式查坑位配置
