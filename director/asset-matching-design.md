# 素材检索与自动匹配机制设计文档

## 一、整体流程

```
文案输入
  ↓
TTS 合成 + 分句
  ↓
自动分镜（按三级分类体系）
  ↓
每镜头生成需求：{镜头类型, 文案, 时长, 需要的画面关键词}
  ↓
素材检索匹配
  ├─ 素材库命中 → 直接调用已有素材
  └─ 未命中 → 标记为「待 AIGC 生成」
  ↓
分镜校准页（三列展示）
  ↓
用户确认
  ↓
批量生成缺失素材（AIGC）
  ↓
渲染输出
```

## 二、标签体系

### 2.1 标签分类

每个素材打两组标签：

| 维度 | 标签 | 说明 |
|------|------|------|
| **内容标签** | 办公、屏幕、城市、自然、科技、人物、抽象、数据、生活、学习 | 画面主体是什么 |
| **情绪标签** | 紧张、平静、活力、焦虑、专业、温暖、未来感、复古 | 画面氛围 |

### 2.2 标签来源

| 来源 | 说明 |
|------|------|
| **手动标注** | 用户上传素材时自己选标签 |
| **文件名提取** | 从文件名自动提取关键词 |
| **AIGC 生成时记录** | 生成素材时的 prompt 自动提取关键词当标签 |

### 2.3 素材元数据格式

`materials/_index.json`：

```json
{
  "文件名.mp4": {
    "type": "video",
    "size": 12345678,
    "tags": ["办公", "屏幕", "专业"],
    "source": "user_upload",
    "created_at": "2026-09-20T12:00:00Z",
    "used_count": 3
  }
}
```

## 三、匹配规则

### 3.1 镜头需求生成

每个分镜自动生成"画面需求"：

```json
{
  "shot_index": 5,
  "text": "每天刷手机两小时",
  "l2_type": "status",
  "needed_tags": ["生活", "屏幕"],
  "needed_mood": "焦虑"
}
```

### 3.2 匹配算法

**第一步：按内容标签匹配**
- 素材的内容标签和需求的 needed_tags 有交集 → 进入候选池
- 交集越多，优先级越高

**第二步：按情绪标签微调**
- 候选池中，情绪标签匹配的优先
- 都不匹配的也保留，但排后面

**第三步：使用频率降权**
- 同一个素材被用过太多次（used_count > 5），优先级降低
- 避免一个素材反复出现

**匹配分数计算：**
```
score = 内容标签交集数 × 3 + 情绪标签匹配 × 2 + (1 / (used_count + 1))
```

- score ≥ 3 → 直接用
- score 1-2 → 可用但标记为「备选」
- score 0 → 待 AIGC 生成

### 3.3 镜头类型 → 默认需求映射

| 二级类型 | 默认内容标签 | 默认情绪 |
|---------|-------------|---------|
| 反常识钩子 | 抽象、科技 | 紧张 |
| 提问钩子 | 抽象、问号 | 思考 |
| 数字钩子 | 数据、屏幕 | 专业 |
| 场景钩子 | 对应文案场景 | 代入 |
| 现状描述 | 生活、日常 | 平静 |
| 误区揭露 | 抽象、错误 | 紧张 |
| 核心定义 | 科技、数据 | 专业 |
| 对比判断 | 抽象、对比 | 思考 |
| 举例说明 | 对应文案例子 | 代入 |
| 数据支撑 | 数据、图表 | 专业 |
| 因果推理 | 流程、箭头 | 理性 |
| 方法论 | 办公、步骤 | 专业 |
| 核心金句 | 抽象、大字 | 震撼 |
| 行动号召 | 城市、出发 | 活力 |

## 四、AIGC 生成与回填

### 4.1 生成 Prompt 模板

```
{画面风格}风格，{内容关键词}，{情绪关键词}氛围，4K，无文字，视频素材
```

示例：
- 输入：needed_tags=["办公", "屏幕"], mood="焦虑"
- 输出 prompt：`现代办公风格，电脑屏幕前的人，焦虑氛围，4K，无文字，视频素材`

### 4.2 生成后自动打标签

生成完成后，从 prompt 中提取关键词：
- "现代办公" → 内容标签：办公
- "电脑屏幕" → 内容标签：屏幕
- "焦虑" → 情绪标签：焦虑

自动写入 `_index.json`。

### 4.3 去重机制

生成前先检查：
1. 素材库是否有类似标签的素材
2. 如果有，直接用，不重复生成

## 五、分镜校准页布局

三列布局：

```
┌──────┬─────────────┬─────────────────┐
│ 序号 │ 镜头类型     │ Remotion 模板   │ 素材来源        │
├──────┼─────────────┼─────────────────┼─────────────────┤
│ 1    │ 🔴 钩子     │ cel-flash-stomp │ 🎥 已有: 办公.mp4 │
│      │ 你收藏了... │                 │                 │
├──────┼─────────────┼─────────────────┼─────────────────┤
│ 2    │ 🟠 痛点     │ blur-slide      │ 🤖 待生成: 生活+焦虑 │
│      │ 90%的人... │                 │                 │
└──────┴─────────────┴─────────────────┴─────────────────┘
```

**素材来源列的三种状态：**
- 🎥 **已有素材**：绿色，显示素材名，可点击预览
- ⚠️ **备选素材**：黄色，匹配度一般，可手动替换
- 🤖 **待生成**：橙色，显示需要的标签，确认后批量生成

## 六、开发优先级

| 阶段 | 内容 | 优先级 |
|------|------|--------|
| P0 | 分镜校准页三列布局 | 先做 |
| P0 | 素材库 _index.json 索引 | 先做 |
| P1 | 简单标签匹配（内容标签交集） | 第二批 |
| P1 | AIGC 生成接口 + 自动打标签 | 第二批 |
| P2 | 情绪标签 + 匹配分数计算 | 第三批 |
| P2 | 使用频率降权 | 第三批 |
| P3 | 手动调整素材分配 | 第四批 |
