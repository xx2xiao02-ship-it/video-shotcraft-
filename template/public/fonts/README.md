# 内置可商用宋体

本目录字体采用 SIL Open Font License 1.1。允许按许可用于商业视频及随软件分发；字体仍有版权，须保留版权和许可证，不单独售卖字体文件。本项目不修改原始字体文件。朱雀仿宋 v0.212 是技术预览版，缺字时回退至思源宋体。

- 思源宋体：https://github.com/adobe-fonts/source-han-serif
- 寒蝉锦书宋：https://github.com/Warren2060/ChillJinshuSong
- 朱雀仿宋：https://github.com/TrionesType/zhuque

完整来源、版本、SHA-256、字重和许可证路径见 manifest.json。fonts.css 用于前端预览；渲染字体由 BundledFonts 等待加载。Windows 发布选择清单已包含本目录（含 OTF/TTF 与许可文件）；本次没有重新构建或验收 EXE。
