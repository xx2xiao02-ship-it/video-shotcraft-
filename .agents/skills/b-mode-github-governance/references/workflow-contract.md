# B 模式工作管线契约

## 上游阶段与产物

| 阶段 | 上游入口 | 必须存在的产物 | 通过条件 |
|---|---|---|---|
| ① 口播稿 | 工程输入 | 原稿、配音 | 原稿和配音对应 |
| ② 时间戳 | `scripts/timestamps_cpu.py` 或上游等价入口 | `audio/timestamps.json`、`remotion/timing.json` | 文本逐字一致，时间连续 |
| ②-1 语义 | `scripts/semantic_annotate.py` | `semantics.json` | `sem`、`need`、`weight`、实体合法；完成后回填 `shot` |
| ③ 素材 | 上游素材清单规则 | `sources.md`、真实文件 | 路径存在，来源可追溯 |
| ④ 分镜 | `scripts/card_match.py` | `SHOTBOOK.md`、`shots.json`、候选表 | 每镜有素材行、选卡行、版式行、蒙皮行和未完成清单 |
| ④→⑤ 预检 | `scripts/preflight.py` | `qa/preflight-result.json` | 无 FAIL；WARN 必须有处理或记录 |
| ⑤ 实现 | 上游模板源码和工程场景 | `src/cards/<slug>.tsx`、参数和素材绑定 | 卡源码可追溯，参数和槽位未被覆盖 |
| ⑥ 渲染 | `scripts/render_shots.mjs` | 分段视频、分段音频、合成视频 | 分段边界连续，入口是上游分段渲染器 |
| ⑦ 验收 | 上游 lint、QA、ffprobe | QA 报告、抽帧/contact sheet | 解码、音频、卡片、素材、时间和布局对账通过 |
| ⑧ 交付 | 工作台/文件交付 | 可播放文件和交付记录 | 用户拿到文件并单独审核 |

## 运行时对账

按以下顺序核对，任何一项不一致都阻断交付：

1. `semantics.json` 的 `shot` 与 `SHOTBOOK`/`shots.json` 镜头范围一致。
2. SHOTBOOK 最终卡在完整已审目录内；属于上游推荐，或按原版语义偏离格式记录至少四字理由。默认返回每语义全部可行推荐，保留上游筛选排序，不事后补造候选，不从推荐第一名自动改选。候选比较报告保留每镜选卡及理由。
3. SHOTBOOK 的最终卡与运行时 `visual-beats.json`、场景注册和实际渲染日志一致。
4. SHOTBOOK 的参数、素材路径、数字人布局和 `cardProps` 与运行时输入一致。
5. `visual-beats` 边界连续覆盖，模板原生帧数独立记录；前8秒开始的镜头逐个满足原卡完整 `nativeFrames <= 90`（30fps），实际占用含驻留不超过3.4秒。规划和成片绑定均检查，候选旧通过不能豁免。
6. 小于2.5秒的视觉拍不安排数字人；人物镜头绑定真实素材。连续30镜不同观点不重复，同一观点强关联承接须逐镜记录pointId、continuesShotId和至少四字reason。每镜首秒须有有效主体承接，装饰编号、色块、箭头和底部字幕不能代替关键词前内容。
7. 输出视频通过 ffprobe、完整解码、音频存在和关键帧抽检；旧输出只能作为对照，不能作为本次通过证据。

## 用户追加规则的接入方式

用户新增规则先写入本次 SHOTBOOK 和机器预检，再决定是否上升为全局规则。已确认的开场短模板、自然语义节奏、2.5秒数字人门槛和30镜去重（同观点承接例外）属于本地适配；不得冒称GitHub原文，也不能把模板原生时长误当成语义拍时长。

## 失败处理

- `preflight` FAIL：停止实现/渲染，修复缺项后从预检重跑。
- 候选、SHOTBOOK、运行时不一致：回到分镜和绑定契约修复，不用手工白名单兜底。
- `spawn EPERM`：记录 Windows 子进程阻断，在隔离目录重试；未完成真实渲染前状态保持阻断。
- 真实素材、数字人或外部服务不可用：保留已完成产物并明确标记未完成，不伪造通过。


## 模板动效15%变速（用户2026-10-16批准的本地适配）

- 仅原卡动效允许0.85～1.15倍速。以原生首尾帧跨度 / 输出首尾帧跨度计算实际速度，整数帧量化后仍不得越限；不是把时长简单增减15%。首尾完整、动作顺序不变，不能裁切、倒放或改原卡运动参数。
- 分镜可填 nativePresentation.playbackRate；省略时优先1倍，原卡略长则可在15%内完整适配。正式timeline每个motion记录实际playbackRate；旧1倍计划兼容。长镜头仍在原卡主体完整可见处明确驻留。
- 配音、数字人口型、字级输出锚点及真实切镜边界不变。变速仅作用于NativePresentationRoot内卡片，WordRevealRoot在外层；模板音效按同一映射迁移。卡内有hostSrc或音视频槽位时不得变速，须重新选卡，不能把口型一起拉伸。
- 开场原卡仍须完整时长≤3秒，前8秒实际镜头≤3.4秒；108已审库、30镜去重、候选外语义理由、首秒内容和关键词窗口校验继续生效。超速、参数/素材不合适的镜头返回编导重选卡，不自动挑推荐第一名，不补画。
- 改速后重新运行分镜、字级、素材、全量预检和样片审核；原配音、成功人物素材及旧片保留。技术通过不等于人工验收，新增模型请求仍需单次费用授权。
